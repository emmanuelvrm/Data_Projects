# Data Projects

Projetos de dados que mais gostei de desenvolver. Cada um deles agora vive em **repositório próprio**, com o histórico de commits preservado, documentação, `requirements.txt` e instruções de execução.

| Projeto | O que faz | Tecnologias | Repositório |
| ------- | --------- | ----------- | ----------- |
| **Análise de Inadimplentes** | Análise exploratória de clientes de uma instituição financeira para entender os fatores ligados à inadimplência | Python, pandas, seaborn, SciPy | [analise-inadimplentes](https://github.com/emmanuelvrm/analise-inadimplentes) |
| **Desempenho ENEM 2021** | Previsão da média do ENEM a partir de dados socioeconômicos (LightGBM, R² ≈ 0,32) | Python, PyCaret, LightGBM, statsmodels | [desempenho-enem-2021](https://github.com/emmanuelvrm/desempenho-enem-2021) |
| **Depressão e Hábitos Saudáveis** | Modelo (Extra Trees) para inferir sintomas depressivos a partir de hábitos saudáveis, com dados do NHANES | Python, PyCaret, scikit-learn | [inferencia-depressao-habitos-saudaveis](https://github.com/emmanuelvrm/inferencia-depressao-habitos-saudaveis) |
| **Recomendação de jogos para streamers** | Recomendador baseado em conteúdo para streamers da Twitch (projeto final do curso Tera, em grupo) | Python, pandas, Streamlit, APIs Twitch e IGDB | [recomendacao-jogos-twitch](https://github.com/emmanuelvrm/recomendacao-jogos-twitch) |
